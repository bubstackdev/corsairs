# Native symbol caching

The v0.3 loader caches successful native symbol addresses per open library.
It owns each symbol name, serializes first resolution with a mutex, retries
failures and retains the existing thread-confined native session. A cache entry
does not outlive its library or introduce a new callable ABI. Exposed pointer
provenance is preserved when storing/reconstructing an address.

Three alternating before/after pairs use the same release phase driver,
fixture bytes and compute policy. The only changed library source is
`native/loader.rs`. Every warmup and measured result is exact. CPU medians of
the three process medians, in microseconds:

| API phase | Before | Cached |
| --- | ---: | ---: |
| Worker marker | 2.209 | 2.125 |
| Tiny input upload | 554.520 | 20.625 |
| Tiny input download | 361.604 | 4.604 |
| Owned inference/readback | 1,180.562 | 34.000 |
| Retained inference | 797.770 | 15.000 |
| Retained inference/readback | 1,168.646 | 20.354 |

This closes the measured small-call lookup bottleneck for the tested CPU
fixture. The GPU phase sweep also checks exact outputs, but its phase timings
vary substantially; it is not a general GPU speedup claim. Each process uses
ten warmups and 100 samples per phase, with validation and drain outside the
timer. The existing [protocol](evidence/v0.3-benchmarks/build/PROTOCOL.md)
defines those boundaries.

[Build identities and source pins](evidence/v0.3-symbol-cache/build-manifest.json),
[all samples/processes](evidence/v0.3-symbol-cache/checks.json), and
[native observation](evidence/v0.3-symbol-cache/native.json) are retained.
The controller checks the frozen old executable and identical benchmark sources
before dispatch; rebuilding this isolated comparison requires the source stage
where only the loader differs from its baseline.

Pure tests cover name ownership/content equality, independent cache instances,
retry after a failed resolution, and concurrent first requests resolving once.
Default workspace tests and strict all-target/all-feature clippy pass at this
stage. An independent static review found no concrete defect in library
lifetime, asynchronous pending-call ownership, pointer provenance or locking.
The mutex is released before invoking any resolved function. Custom reentrant
symbol resolvers are not part of the fixed system-framework call paths reviewed.
Final native and artifact qualification still applies after subsequent changes.
