# Corsairs v0.3.1

v0.3.1 is a patch release of [v0.3.0](v0.3-release.md) containing the
remediations from the [codebase review](../CODEBASE-REVIEW.md). The public API,
supported bounds, and known exclusions are unchanged.

## Changes from v0.3.0

- **Bounded native chain provenance (M1).** Native outputs no longer gain a
  fresh alias origin on every call. Inherited upload origins and reserved origin
  `0` still reject upload/output and output/output overlap. A long chain of
  `run_native` calls now keeps constant lineage instead of O(N) per result and
  O(N²) cumulative bookkeeping.
- **Waker callbacks outside the result lock (L1).** `Task::poll` clones the new
  waker before locking and drops the replaced waker after unlocking. A custom
  waker whose destructor waits on the same runtime can no longer deadlock the
  worker.
- **Reference acceptance (M2, M3).** These changes affect the repository's
  development scripts only; the published crate does not contain them. Reference
  collection and golden freezing now require OS-backed Core AI and a clean
  process exit for `passed`/`expected_error`.

## Release gates

The changed crate sources are `native/owned/handles.rs` and `worker.rs`. This
patch reruns the gates that cover them on the recorded macOS 27.0.1 (26A434)
host with Rust 1.99.0:

- `cargo fmt --all --check` and `cargo clippy --offline --workspace --all-targets --all-features -- -D warnings`
- `cargo test --offline -p corsairs --no-default-features -- --include-ignored`:
  50 library tests including the six native lifecycle tests, plus CLI and doctest
- `scripts/check_v02.py --native`: debug/release native parity (32) and Metal
  parity (64) configurations, dynamic-shape and native-handle drivers
- `scripts/check_v01.py --native --cycles 10000 --loads 100 --dropped 100`:
  32 positive and 16 negative configurations and 80,000 checked stress inferences
- Python reference regressions (12 tests)
- `scripts/check_package_v03.py --native`: every archive member, extracted-package
  and isolated-consumer builds, eight native example runs, packaged CLI and BF16
  checks — [candidate verification](evidence/v0.3.1/package-verification.json)

The large-tensor capacity, GPU rejection, H3 and Krea gates were not rerun. Those
paths are unchanged from v0.3.0, and their retained
[v0.3 evidence](evidence/v0.3-final/aggregate.json) still applies to them.
